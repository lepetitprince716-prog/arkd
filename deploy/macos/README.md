# macOS deployment (launchd)

Install the LaunchAgent generated by arkd itself — it embeds the absolute path
of the current binary and puts logs under `maa.user_dir`:

```sh
arkd launchd print > ~/Library/LaunchAgents/ai.arkd.daemon.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/ai.arkd.daemon.plist
```

Check it is running:

```sh
launchctl print gui/$(id -u)/ai.arkd.daemon
curl -s http://127.0.0.1:7717/healthz
```

Logs:

- `arkd.out.log` and `arkd.err.log` inside the configured `maa.user_dir`
  (default `~/.local/state/arkd`).

Restart / unload:

```sh
launchctl kickstart -k gui/$(id -u)/ai.arkd.daemon          # restart
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/ai.arkd.daemon.plist
```

## Gotchas

- MAA.app must not be connected to the same PlayTools port (`127.0.0.1:1717`)
  at the same time as arkd — quit MAA.app or disable its MaaTools link first.
- PlayCover cannot be screenshotted while the game window is minimised or on
  another macOS Space; keep the window visible on the active Space for
  `screen_capture` and the battle primitives to see real frames.
